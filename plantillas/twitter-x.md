# Plantillas para Twitter/X

## Formatos disponibles en Twitter/X

| Formato | Límite | Ideal para |
|---------|--------|------------|
| Tweet de texto | 280 caracteres | Opiniones, tips rápidos, preguntas |
| Tweet con imagen | 280 chars + 1-4 imágenes | Infografías, capturas, memes |
| Hilo (thread) | Tweets encadenados (sin límite) | Contenido largo, tutoriales, historias |
| Video | 2 min 20 seg (140 seg) | Tutoriales cortos, clips |
| Encuesta | 4 opciones, hasta 7 días | Engagement, investigación de audiencia |
| Spaces | Audio en vivo | Conversaciones, networking |

## Plantilla 1: Tweet de opinión/take caliente

### Estructura

```
[Afirmación provocadora o contraintuitiva sobre tu industria].

[1-2 líneas que justifiquen o desarrollen la idea].

[Pregunta o invitación al debate]
```

### Ejemplos

```
El engagement rate importa más que la cantidad de seguidores.

Una cuenta con 1K seguidores y 10% de engagement vende más
que una con 100K y 0.5%.

¿Preferís tener muchos seguidores o una comunidad activa?
```

```
Impopular opinion: no necesitás publicar todos los días
para crecer en redes.

Necesitás publicar BIEN los días que publiques.

Calidad > cantidad. Siempre.
```

## Plantilla 2: Tweet de tip rápido

### Estructura

```
[Emoji] Tip de [tema]:

[Consejo concreto y accionable en 1-3 líneas]

(Guardá este tweet para después)
```

### Ejemplos

```
💡 Tip de copywriting:

Empezá siempre por el beneficio, no por la característica.

No: "Nuestro curso tiene 40 horas de contenido"
Sí: "En 40 horas vas a dominar [habilidad]"
```

```
🎯 Tip de Instagram:

Los carruseles tienen 3x más alcance que las imágenes solas.

Usá la primera slide como gancho y la última como CTA.

Guardá 🔖
```

## Plantilla 3: Hilo (thread) educativo

### Estructura

**Tweet 1 (Hook):**
```
[Título del hilo + promesa de valor]

🧵 Hilo:
```

**Tweet 2 (Contexto):**
```
[Por qué este tema importa / para quién es]
```

**Tweets 3-8 (Contenido - 1 punto por tweet):**
```
[Número]. [Título del punto]

[Explicación en 2-3 líneas]

[Ejemplo si aplica]
```

**Tweet 9 (Resumen):**
```
Resumen:

1. [Punto 1]
2. [Punto 2]
3. [Punto 3]
4. [Punto 4]
5. [Punto 5]
```

**Tweet 10 (CTA):**
```
Si te sirvió este hilo:

1. Retuiteá el primer tweet para que llegue a más personas
2. Seguime @tucuenta para más contenido así
3. Dejame en respuesta qué tema querés que cubra en el próximo hilo
```

### Ejemplo de hilo completo

```
Tweet 1:
7 formas de escribir mejores hooks para redes sociales
(y captar atención en los primeros 3 segundos)

🧵 Hilo:

Tweet 2:
El 80% de las personas solo lee la primera línea.

Si tu hook no engancha, el resto del contenido no importa.

Acá van 7 fórmulas probadas:

Tweet 3:
1. La pregunta directa

"¿Sabías que el 70% de los carritos de compra se abandonan?"

Funciona porque activa la curiosidad y hace que el lector
quiera saber la respuesta.

Tweet 4:
2. El dato sorprendente

"Las empresas que publican en LinkedIn obtienen 2x más engagement los martes."

Un número específico y concreto siempre genera más confianza.

Tweet 5:
3. La negación provocadora

"No necesitás un gran presupuesto para hacer marketing digital."

Contradecir una creencia popular genera interés inmediato.

[... continúa con los demás puntos]
```

## Plantilla 5: Tweet conversacional / engagement

### Fórmulas

**Pregunta abierta:**
```
Pregunta para [tu audiencia]:

¿Cuál es [pregunta sobre su experiencia/opinión]?

Empiezo yo: [tu respuesta]
```

**Completar la frase:**
```
Completá la frase:

"[Tema] es ____________"

(Las mejores respuestas las comparto en stories)
```

**Esto o aquello:**
```
🤔 ¿Qué preferís?

RT → [Opción A]
❤️ → [Opción B]
```

**Controversial ranking:**
```
Rankeá de mejor a peor:

A. [Opción]
B. [Opción]
C. [Opción]
D. [Opción]

Mi ranking: A > C > D > B

¿Y el tuyo?
```

## Plantilla 6: Tweet de storytelling

### Estructura

```
[Situación inicial - el problema o punto de partida]

[El punto de quiebre - qué cambió]

[El resultado - qué lograste/aprendiste]

[La lección - qué puede aplicar tu audiencia]
```

### Ejemplo

```
Hace 1 año tenía 200 seguidores y 0 clientes por redes.

Cambié 3 cosas:
- Publiqué contenido útil (no solo vender)
- Respondí TODOS los comentarios
- Compartí mis errores, no solo mis logros

Hoy: 15K seguidores y el 60% de mis clientes llegan por redes.

La autenticidad vende más que la perfección.
```

### Estructura


## Tips específicos para Twitter/X

1. **Primera línea es todo** - En el timeline solo se ven las primeras líneas; hacelas irresistibles
2. **Respondé a cuentas grandes** - Con aportes genuinos, no spam
3. **Usá espacios en blanco** - Los tweets con saltos de línea se leen mejor
4. **Twitteá en hora pico** - Y respondé comentarios en los primeros 15 minutos
5. **Hacé hilos los martes y jueves** - Son los días con mejor rendimiento
6. **No pongas links en el tweet principal** - Bajalo a un reply para mejor alcance
7. **Sé consistente** - 2-5 tweets por día es un buen rango

## Checklist antes de twittear

- [ ] El tweet se entiende sin necesidad de leer un hilo
- [ ] La primera línea engancha
- [ ] No tiene errores de tipeo
- [ ] Si es un hilo, el último tweet tiene CTA
- [ ] No hay links en el tweet principal (ponerlos en reply)
- [ ] El tono es coherente con mi marca
