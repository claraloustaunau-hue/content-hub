# Plantillas para Facebook

## Formatos disponibles en Facebook

| Formato | Características | Ideal para |
|---------|----------------|------------|
| Post de texto | Sin límite práctico | Historias, preguntas, opiniones |
| Post con imagen | 1-10 imágenes | Productos, infografías, fotos |
| Video | Hasta 240 min | Tutoriales, testimonios, lives |
| Reel | Hasta 90 seg, vertical | Alcance orgánico, trends |
| Story | 1080x1920, 20 seg | Contenido efímero, interacción |
| Evento | Fecha, lugar, detalles | Webinars, lanzamientos, meetups |
| Encuesta | Opciones múltiples | Engagement, feedback |
| Live | Hasta 8 horas | Q&A, lanzamientos, tutoriales en vivo |

## Plantilla 1: Post de valor (educativo/informativo)

### Estructura

```
[Hook - pregunta o dato que capture atención] 🎯

[Desarrollo del tema - 3 a 5 párrafos cortos]

[Párrafo 1: Contexto del problema]

[Párrafo 2: Tu solución o perspectiva]

[Párrafo 3: Ejemplo o dato concreto]

[CTA claro]

💬 ¿Qué opinás? Contame en los comentarios.
📌 Guardá este post para después.
🔄 Compartilo si le puede servir a alguien.
```

### Ejemplo

```
¿Sabías que el 65% de las personas son aprendices visuales? 🧠

Esto significa que tu contenido en redes sociales debería
ser VISUAL primero, texto después.

La próxima vez que crees un post, preguntate:
"¿Alguien entendería el mensaje solo con la imagen?"

Si la respuesta es sí, vas por buen camino.
Si la respuesta es no, necesitás mejorar el diseño.

Acá van 3 tips para hacer tu contenido más visual:

1️⃣ Usá colores contrastantes para resaltar el texto clave
2️⃣ Incluí íconos o ilustraciones que refuercen el mensaje
3️⃣ Menos texto = más impacto visual

💬 ¿Cuál de estos tips ya aplicás? Contame 👇
```

## Plantilla 5: Post para grupos de Facebook

### Estructura

```
[Pregunta o tema relevante para el grupo] 🤔

[Contexto breve - por qué preguntás o por qué compartís]

[Tu aporte de valor - tip, experiencia, recurso]

[Invitación a la conversación]

PD: [Dato extra o aclaración]
```

### Tips para grupos

- Aportá valor genuino antes de promocionar
- Respondé preguntas de otros miembros
- No hagas spam ni autopromoción constante
- Seguí las reglas del grupo
- Interactuá con las publicaciones de otros

## Tips específicos para Facebook

1. **Los videos nativos tienen prioridad** - Subí el video directo, no compartas link de YouTube
2. **Facebook prioriza conversaciones** - Posts que generan comentarios largos tienen más alcance
3. **Usá Facebook Groups** - El alcance orgánico en grupos es significativamente mayor que en páginas
4. **Los reels tienen boost de alcance** - Facebook está impulsando este formato
5. **Evitá el engagement bait** - "Dale like si..." penaliza tu alcance
6. **Compartí contenido nativo** - Los links externos tienen menos alcance que posts nativos
7. **Respondé rápido** - La velocidad de respuesta afecta el alcance del post

## Checklist antes de publicar en Facebook

- [ ] El post tiene un hook claro en las primeras líneas
- [ ] La imagen/video es de buena calidad
- [ ] El CTA es específico y claro
- [ ] No es engagement bait ("dale like si...")
- [ ] El contenido es nativo (no solo un link)
- [ ] Elegí el mejor horario según mi audiencia
- [ ] Si es un evento, todos los datos están completos
- [ ] El tono es coherente con mi marca
