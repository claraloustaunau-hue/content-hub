# Content Hub - Contenido para Redes Sociales

Kit completo de recursos, plantillas y estrategias para crear contenido efectivo en redes sociales.

## Estructura del repositorio

```
content-hub/
├── README.md
├── estrategia-contenido.md        # Estrategia general y objetivos
├── calendario-contenido.md        # Calendario editorial mensual
├── buenas-practicas.md            # Guía de copywriting y mejores prácticas
├── banco-de-ideas.md              # Banco de ideas organizadas por categoría
└── plantillas/
    ├── instagram.md               # Plantillas para Instagram (feed, stories, reels)
    ├── twitter-x.md               # Plantillas para Twitter/X (tweets, hilos)
    ├── linkedin.md                # Plantillas para LinkedIn (posts, artículos)
    ├── facebook.md                # Plantillas para Facebook (posts, eventos)
    └── tiktok.md                  # Plantillas para TikTok (guiones, hooks)
```

## Cómo usar este repositorio

1. **Definí tu estrategia** - Empezá por `estrategia-contenido.md` para establecer objetivos, audiencia y tono de voz.
2. **Planificá tu calendario** - Usá `calendario-contenido.md` para organizar publicaciones semanales y mensuales.
3. **Elegí una plantilla** - Entrá a la carpeta `plantillas/` y seleccioná la red social donde querés publicar.
4. **Aplicá buenas prácticas** - Consultá `buenas-practicas.md` para optimizar cada publicación.
5. **Buscá inspiración** - Revisá `banco-de-ideas.md` cuando necesites nuevas ideas de contenido.

## Para quién es este recurso

- Community managers
- Emprendedores que manejan sus propias redes
- Equipos de marketing digital
- Freelancers de contenido
- Cualquier persona que quiera mejorar su presencia en redes sociales
